About

I'm a software engineer who has worked on blockchain systems since 2018, starting with Hyperledger Indy identity infrastructure and moving through EVM protocols to Polkadot runtimes and FHE-enabled chains. Since 2024 I've been an open-source developer with OpenZeppelin, contracting through my own practice.

I like problems that sit between layers: a pallet that has to expose an EVM precompile, a decrypt flow that has to be authorised on-chain and executed off-chain, a build that has to be byte-for-byte reproducible. I write the tests first, keep PRs reviewable, and leave documentation behind.
